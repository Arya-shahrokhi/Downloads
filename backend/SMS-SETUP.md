# راه‌اندازی پیامک کالاوران (Kavenegar)

این ماژول پیامک ثبت سفارش، تغییر وضعیت سفارش و کد تایید شماره موبایل ایران را اضافه می‌کند.

## ۱) تنظیم پنل پیامکی
1. در پنل Kavenegar حساب بسازید و اعتبار/خط ارسال مناسب تهیه کنید.
2. API Key را از پنل بردارید.
3. برای ارسال کد از مسیر Verify Lookup، یک قالب تایید (Template) در پنل بسازید و نام دقیق آن را در `KAVENEGAR_OTP_TEMPLATE` قرار دهید. اگر قالب ندارید، سرویس از پیامک معمولی استفاده می‌کند؛ این روش ممکن است بسته به خط/مجوز حساب برای کد تایید مناسب نباشد.
4. هیچ‌وقت API Key را در React، فایل‌های عمومی یا GitHub قرار ندهید.

## ۲) متغیرهای محیطی backend
مقادیر زیر را در `backend/.env` محلی و متغیرهای محیطی سرور قرار دهید. `.env` را commit نکنید.

```dotenv
SMS_ENABLED=true
KAVENEGAR_API_KEY=کلید_API_شما
KAVENEGAR_SENDER=
KAVENEGAR_OTP_TEMPLATE=
SMS_ADMIN_PHONE=09xxxxxxxxx
SMS_OTP_SECRET=یک_رشته_تصادفی_طولانی_و_منحصر_به_فرد
SMS_OTP_REQUIRED=false
```

برای تولید راز امن: `openssl rand -hex 32`. فرم ثبت‌نام React به endpointهای کد تایید متصل شده است. برای تست اولیه، `SMS_OTP_REQUIRED=false` بماند؛ بعد از تنظیم کلید و قالب پیامک و تست موفق، `SMS_OTP_REQUIRED=true` کنید تا ثبت‌نام بدون تایید شماره در سمت سرور رد شود.

## ۳) API کد تایید
- `POST /api/sms/otp/register/request` با بدنه `{"phone":"09123456789"}`
- `POST /api/sms/otp/register/verify` با بدنه `{"phone":"09123456789","code":"123456"}`

کد ۶ رقمی، ۵ دقیقه اعتبار، حداقل فاصله یک دقیقه برای ارسال دوباره و حداکثر ۵ تلاش دارد. نتیجه تایید برای ثبت‌نام تا ۱۵ دقیقه معتبر است. در صورت فعال‌سازی `SMS_OTP_REQUIRED=true`، کنترل سمت سرور انجام می‌شود.

## ۴) پیامک سفارش
بعد از ثبت سفارش، برای مشتری و شماره مدیر (`SMS_ADMIN_PHONE`؛ در نبود آن `ADMIN_PHONE`) پیامک ارسال می‌شود. تغییر وضعیت سفارش نیز به مشتری پیامک می‌شود. خطای پیامک سفارش نباید ثبت سفارش را خراب کند و فقط در لاگ سرور ثبت می‌شود.

## ۵) انتشار
1. نصب/بررسی با نسخه Node.js دارای `fetch` و `AbortSignal.timeout` (Node 18+).
2. تنظیم متغیرها در پنل سرویس میزبانی، نه در GitHub.
3. انتشار شاخه تغییرات پس از بازبینی و merge.
4. ابتدا با شماره خودتان و یک سفارش آزمایشی کم‌هزینه تست کنید؛ ارسال پیامک هزینه دارد.
